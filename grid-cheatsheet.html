Terminology

Grid Container
main box that holds and organizes all the grid items.
Grid Item
element inside a grid container that is placed in the grid.
Track
row or column in a grid that helps organize the layout.
Cell
single space in a grid where a row and column meet.
Area
section of the grid made up of one or more cells.
Explicit Grid
rows and columns that you create yourslef using CSS.
Implicit Grid
rows or columns that CSS creates automatically when needed.
Grid Template
way to plan how the rows and columns of a grid will look.
Gutters
empty spaces between rows and columns in a grid.
Grid Naming
Giving names to grid lines or areas to make organizing the layout easier.
